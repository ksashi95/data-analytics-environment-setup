# R Setup

## Goal

Install R and verify that the R console works independently of RStudio.

## Installation

Install a current R release appropriate for your operating system.

On Windows, a typical installation directory looks like:

```text
C:\Program Files\R\R-x.x.x
```

Use `<R-VERSION>` rather than hard-coding a machine-specific version in project documentation.

## Verify R

Open the R console and run:

```r
R.version.string
```

You can also check a package version with:

```r
packageVersion("ggplot2")
```

## Recommended Workflow

This setup uses the standard R console plus Jupyter/IRkernel for notebooks. RStudio is not required.

## Installing Packages

Example:

```r
install.packages("ggplot2")
```

Then load it:

```r
library(ggplot2)
```
