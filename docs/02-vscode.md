# VS Code Setup

## Goal

Use Visual Studio Code as the main development environment for Python, R notebooks, Jupyter, and SQL Server.

## Recommended Extensions

- Python
- Jupyter
- SQL Server (MSSQL)

The R workflow in this repository uses **R + IRkernel + Jupyter**. A dedicated R language extension is optional and is not required for the notebook workflow described here.

## Python Workflow

1. Open VS Code.
2. Open a project folder.
3. Create a `.py` file or `.ipynb` notebook.
4. Select the intended Python interpreter.
5. Run the code.

## Notebook Workflow

For `.ipynb` files, VS Code uses the Jupyter extension to provide notebook cells and kernel selection.

## SQL Workflow

The MSSQL extension allows SQL queries to be opened and executed directly in VS Code after a SQL Server connection has been configured.

## Best Practice

Keep one project in one folder and open that folder in VS Code. This makes notebooks, scripts, SQL files, documentation, and project configuration easier to manage.
